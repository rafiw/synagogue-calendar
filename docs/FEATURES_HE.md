# ✨ תכונות

## 🕯️ לוח זיכרון - תכונת ייבוא CSV

לוח הזיכרון כולל תכונה מתקדמת לייבוא מרובה של נפטרים מקובץ CSV, המאפשרת הזנת נתונים בכמויות גדולות בקלות.

### 📥 תכונת ייבוא CSV

ייבאו מספר רב של רשומות נפטרים בבת אחת באמצעות קובץ CSV - מושלם להעברת נתונים והזנה המונית.

#### עמודות נתמכות בקובץ CSV:

| כותרות באנגלית                   | כותרות בעברית      | תיאור                       | דוגמה            |
| -------------------------------- | ------------------ | --------------------------- | ---------------- |
| `name`                           | `שם`               | שם מלא (חובה)               | `משה כהן`        |
| `gender`, `male`, `ismale`       | `מין`              | מין (male/true/1/זכר = זכר) | `male` או `זכר`  |
| `dateofbirth`, `dob`, `birth`    | `תאריך לידה`       | תאריך לידה (לועזי)          | `1950-01-15`     |
| `dateofdeath`, `dod`, `death`    | `תאריך פטירה`      | תאריך פטירה (לועזי)         | `2020-05-20`     |
| `hebrewdateofbirth`, `hebrewdob` | `תאריך לידה עברי`  | תאריך לידה (עברי)           | `ט"ו שבט תש"י`   |
| `hebrewdateofdeath`, `hebrewdod` | `תאריך פטירה עברי` | תאריך פטירה (עברי)          | `כ"ז אייר תש"פ`  |
| `photo`, `photourl`              | `תמונה`            | קישור לתמונה                | `https://...`    |
| `tribute`, `memorial`            | `זיכרון`           | טקסט הנצחה                  | `אב וסב אהוב...` |

#### דוגמת קובץ CSV בעברית:

```csv
שם,מין,תאריך לידה,תאריך פטירה,תאריך לידה עברי,תאריך פטירה עברי,תמונה,זיכרון
משה כהן,זכר,1940-05-10,2021-03-15,י' אייר תש"ח,ט"ו אדר תשפ"א,https://example.com/photo.jpg,אב וסב אהוב
שרה לוי,נקבה,1950-07-20,2022-01-10,כ' תמוז תש"י,י' שבט תשפ"ב,,מורה מסורה ואהובה
יעקב וינר,זכר,1935-12-05,2020-08-25,ה' כסלו תרצ"ו,כ"ה אב תש"פ,https://example.com/yaakov.jpg,גבאי נאמן
```

#### דוגמת קובץ CSV באנגלית:

```csv
name,gender,dateofbirth,dateofdeath,hebrewdateofbirth,hebrewdateofdeath,photo,tribute
Moshe Cohen,male,1940-05-10,2021-03-15,10 Iyar 5700,15 Adar 5781,https://example.com/photo.jpg,Beloved father and grandfather
Sarah Levy,female,1950-07-20,2022-01-10,20 Tammuz 5710,10 Shevat 5782,,Devoted and loving teacher
Yaakov Wiener,male,1935-12-05,2020-08-25,5 Kislev 5696,25 Av 5780,https://example.com/yaakov.jpg,Faithful gabbai
```

#### אופן השימוש:

1. **הכינו קובץ CSV** עם הכותרות הנדרשות (באנגלית או בעברית)
2. **מלאו את הנתונים** - לפחות שם הוא שדה חובה
3. **עברו להגדרות** → לשונית זיכרון/נפטרים
4. **לחצו על כפתור "ייבא CSV"**
5. **בחרו את קובץ ה-CSV** שלכם
6. **האפליקציה תייבא** את כל הרשומות התקינות

#### הערות חשובות:

- ✅ **שם הוא שדה חובה** - שורות ללא שם יידלגו
- ✅ **כותרות יכולות להיות באנגלית או בעברית** - האפליקציה מזהה את שתי השפות
- ✅ **מין כברירת מחדל** - אם לא צוין, הברירת מחדל היא נקבה
- ✅ **תבנית פשוטה** - כל הרשומות המיובאות מקבלות תבנית "פשוטה" כברירת מחדל
- ✅ **עריכה לאחר ייבוא** - ניתן לערוך כל רשומה לאחר הייבוא
- ✅ **דילוג אוטומטי** - שורות לא תקינות מדולגות אוטומטית
- ✅ **הוספה לרשומות קיימות** - הייבוא מוסיף לרשומות הקיימות (לא מחליף אותן)
- ⚠️ **שימו לב לפורמט התאריכים** - תאריכים לועזיים צריכים להיות בפורמט `YYYY-MM-DD`
- 💡 **טיפ**: אפשר להשתמש ב-Excel או Google Sheets ליצירת הקובץ, ואז לשמור בפורמט CSV

#### שדות אופציונליים:

כל השדות מלבד השם הם אופציונליים. אפשר לייבא רק עם שם ולהוסיף את שאר הפרטים מאוחר יותר:

```csv
שם
משה כהן
שרה לוי
יעקב וינר
```

#### יתרונות תכונת הייבוא:

- ⏱️ **חיסכון בזמן** - במקום להזין ידנית כל רשומה, ייבאו מאות רשומות בשניות
- 📊 **העברת נתונים** - העבירו נתונים בקלות ממערכות אחרות
- 🔄 **עדכונים המוניים** - הוסיפו רשומות רבות בבת אחת
- 📝 **גיבוי ושחזור** - ייצאו את הנתונים ל-CSV (באמצעות גיבוי GitHub) וייבאו מחדש במקרה הצורך
- 🎯 **דיוק** - הכנת הקובץ במחשב מפחיתה שגיאות הקלדה
